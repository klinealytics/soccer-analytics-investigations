# Soccer analytics investigationsQuestions about soccer tactics and player skill, investigated with freepublic data. Each question has its own notebook.## Contents- `downloading_data.ipynb`: loads StatsBomb open data and checks which  competitions have 360 data- `soccer_utils.py`: shared helpers for loading and caching StatsBomb events## DataStatsBomb open data, loaded with mplsoccer's `Sbopen`. Data is cached locallyin `data/` and not included in the repo; the loaders in `soccer_utils.py`download it on first run.
